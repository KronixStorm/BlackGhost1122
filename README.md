## 🚀 Featured Project

### [MOSIF: Micro Operating System Integration Framework (DOS)](https://github.com/KronixStorm/MOSIF-Micro-Operating-System-Integration-Framework-DOS)

A DOS-style "micro operating system" simulation I built **as a kid**: a BIOS-like boot stage, a console OS, a graphical shell, and built-in apps (file manager, notepad, calculator). It's not production code. It's the project that proved to me I wanted to do this for a living.
